# Tareas – Computación II

Tareas de la materia **Computación II** (Actuaría, Universidad Anáhuac Veracruz, otoño 2026).
Trabajo en Python con **pandas** y **matplotlib** en notebooks de Jupyter.

| Tarea | Tema | Archivos |
|---|---|---|
| [Tarea 1](Tarea1_Peliculas/) | Análisis de la base de datos de películas (ejercicio 3) | `tarea1_peliculas.ipynb` |
| [Tarea 2](Tarea2_Cheatsheet_Pandas/) | Acordeón (cheatsheet) de sintaxis de pandas con un DataFrame genérico | `tarea2_cheatsheet_pandas.ipynb`, `base_generica_pandas.csv` |
| [Tarea 3](Tarea3_PivotTables_Lambda/) | Pivot tables y funciones lambda con el dataset de Olist (la tarea empieza en la sección "Nivel 2"; lo anterior son notas de clase) | `tarea3_pivot_tables_lambda.ipynb` |
| [Tarea 6](Tarea6_Barplots_PieCharts/) | Gráficas de barras y de pastel con matplotlib (Olist) | `tarea6_barplots_piecharts.ipynb`, `.pdf` |

## Datos

- **Tarea 1** lee la base de películas directamente desde internet, no necesita archivos extra.
- **Tarea 2** usa `base_generica_pandas.csv`, incluido en su carpeta.
- **Tareas 3 y 6** usan el [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) de Kaggle.
  Los CSV no se suben al repositorio por su tamaño. Para correr los notebooks, descarga el dataset
  y pon los CSV en una carpeta `datos_olist_reales/` en la raíz del repositorio.
